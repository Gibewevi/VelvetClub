# Buissons extérieurs — sources et génération

Ces nouvelles peintures ont été créées avec l’outil intégré image_gen à partir de la référence du joueur du 2 octobre 2026. Aucun ancien buisson du jeu n’a servi de référence. Les sources sont conservées ici pour que les reconstructions du jeu gardent les nouveaux dessins.

`pa_lawn.bush()` prépare quatre sprites de 80 × 56 pixels : deux tailles de feuillage vert, un buisson fleuri étendu et un fleuri compact. L’échantillonnage est au plus proche, les feuilles ont une transparence binaire, et la palette de 32 couleurs n’utilise aucun tramage. Le pied est centré sur le point au sol ; une petite ombre de contact séparée est contenue dans le cadre. Les dimensions au sol des quatre variantes restent inchangées.

Sprites intégrés au jeu : pixel/art/props/lawn_bush_0.png, lawn_bush_1.png, lawn_bush_2.png et lawn_bush_3.png. Les trois sources originales figurent ci-dessous.

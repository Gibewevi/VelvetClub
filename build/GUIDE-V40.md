# Construction V40 — Petite fourgonnette DLH

Lancez **Construction-V40-Fourgonnette.exe**. Les anciennes sauvegardes, y compris les livraisons en cours, restent compatibles.

Le véhicule de livraison est désormais une **petite fourgonnette jaune DLH**, plus compacte et arrondie. Ses portes arrière découvrent les colis et un petit marchepied ; les livreurs chargent leurs cartons juste derrière. Les cônes et les trajets tiennent compte de sa taille.

La carrosserie garde une image stable pendant l'attente. Les petits warnings orange pulsent doucement quand la fourgonnette est garée, sans alterner toute l'image du véhicule. Accélérer le jeu n'accélère plus les lumières ; la pause les fige.

## Recevoir une commande

Achetez un objet dans **Mobilier**, puis placez son fantôme. Tous les achats effectués avant l'arrêt de la fourgonnette rejoignent la même commande. Le premier achat déclenche environ **18 secondes d'attente à vitesse normale**, puis le véhicule arrive par la route.

Deux livreurs transportent les cartons jusqu'aux fantômes, déballent et installent les objets. Les achats effectués pendant le déchargement attendent la tournée suivante.

Le bouton **Livraisons**, sous l'horloge, affiche le suivi. Les fantômes restent déplaçables. Si un accès est bloqué, dégagez le passage ou ajoutez une porte pour permettre une nouvelle tentative.

**Espace** met en pause, **1 / 2** règlent la vitesse et la molette permet de regarder la fourgonnette de plus près.
